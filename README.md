# 番年史 · Anime Atlas

2000–2026 年的日本动画追番表，按首播年月筛选累计热度前 30%，现收录 2,248 部。每年海报连续排列，支持筛选、悬停／长按查看详情、点击标记看过，以及观看记录导入导出。

## 部署

访问地址：https://codphish.github.io/anime-atlas/

本仓库通过 GitHub Pages 从 `main` 分支根目录发布。更新 `index.html`、`game.css`、`game.js` 或 `share-qr.js` 后会自动重新发布；`.nojekyll` 用于直接提供静态文件。所有文件应放在同一目录，不需要 Actions 工作流或后端。

## iPhone 使用

在 Safari 打开部署后的 HTTPS 地址，而不是预览聊天附件。也可以在 Safari 的分享菜单中“添加到主屏幕”。若从其他浏览器或本地文件迁移，先导出观看记录，再在新网页导入；localStorage 按网站地址和浏览器隔离，不自动同步。

海报需要访问 Bangumi 图片服务。页面和片单是静态资源，不需要后端或数据库。观看记录只保存在访问者自己的浏览器里，不上传到 GitHub，不在不同设备间自动同步。

HTML 附件预览即使禁用脚本也可看只读片单；筛选和标记功能需要 JavaScript。

## 像素图鉴与成就

漫画描边、像素收集反馈、短时连击提示及 12 枚铜／银／金／白金奖杯。奖杯按本片单的观看标记计算，覆盖数量、首播年份、剧场版及类型探索；取消标记会回退进度，重复点亮不会再次弹出已通知奖杯。连击仅影响反馈演出，不增加观看数量。

玩家档案支持昵称、最多三部本命、动效强度及音效开关。音效默认关闭，系统“减少动态效果”优先于用户动效设置。原观看记录直接沿用；玩家设置及奖杯通知历史存于同一浏览器，导出时一并备份，兼容旧版仅包含观看记录的备份。奖杯状态始终由实际观看标记重新计算。

“晒战绩”在本机绘制 PNG，包含趣味浓度、观看数量、年份足迹、奖杯、本命作品及网站二维码。不上传记录、不虚构全站排名，也不依赖跨站海报。支持系统图片分享的浏览器可以直接分享，其余可保存图片。清理网站数据会清除本地存档，请定期导出。

## 数据

来源：[Bangumi 官方 Archive](https://github.com/bangumi/Archive)，快照 2026-10-06。热度按累计收藏人数计算，不代表首播当月的历史实时榜单。完整筛选口径可在页面“收录规则与数据来源”查看。

动画名称、简介、海报等权利属于各自权利人和原数据贡献者，条目提供 Bangumi 来源链接。
